# ピッとナマピ（AI学習デスク v4・バーコードスキャナー版）

QRの読み取りを、カメラから専用スキャナー **Eyoyo EY-015P** に変えた版です。
Phase1のゴールは「教材のQRを **ピッ** → 右側に音声・動画が開く」だけです。

- 開く: `https://bgyumi.github.io/study-desk/v3/`
- こどもモード（起動時）: 教材のQRをスキャナーでピッするだけ
- 本ボタン: 読書通帳（なまえカード→本のバーコードでピッ）
- 時計ボタン: さいきん開いた教材（クリックでもう一度開く）
- おやモード: ロゴ「ピッとナマピ」を **1.5秒長押し**（子どもに見えるボタンは置かない）

## スキャナーの準備
1. EY-015P を充電し、2.4Gドングルを Chromebook に挿す
2. v3 を開いて、おやモードの「スキャナー確認」を表示する
3. 何かQRを読む → 表に出れば接続OK
   - 「そのまま」と「US配列で復元」が違う → 配列ずれが起きている（アプリが自動で直すので問題なし）

## QRを読んだときの動き
| 読んだもの | 動き |
|---|---|
| YouTube | 右側に埋め込み表示（関連動画なし） |
| mp3・mp4などのファイル | 右側でそのまま再生 |
| 許可サイトのページ | 新しいタブで開く（タブは1つを使い回す。閉じるとアプリの最初の画面に戻る） |
| 許可していないサイト | **v3.2では許可サイト機能をOFFにしているので開く**。おやモードのスイッチを外すと「おうちの人に きいてね」→「承認待ち」になる |
| なまえカード（SD-USER-1〜3） | その子に切り替え（15分なにも読まないと解除） |
| 本の裏の上のバーコード（ISBN） | 書名をしらべて、その子の読書通帳に1冊追加。名前より先に読んでも、2分以内に名前を読めば記録 |
| 本の裏の下のバーコード | 「うえの バーコードを ピッ してね」と案内 |

## ファイル構成
```
v3/
├ index.html     画面の骨組み（こども／おや）
├ css/style.css  見た目
├ js/config.js   設定値（スキャナー判定の速さ・初期の許可サイトなど）
├ js/scanner.js  スキャナー入力を受け取る（配列ずれ補正もここだけ）
├ js/router.js   読んだ文字列が URL／カード／ISBN のどれか判定
├ js/allow.js    許可サイトと承認待ち
├ js/history.js  さいきん開いた教材・教材サイトの呼び名
├ js/kids.js     子ども3人の名前・色・いま使っている子
├ js/reading.js  読書通帳（書名しらべ：openBD→Google Books）・バックアップ
├ cards.html     なまえカード印刷ページ
├ vendor/        QRコード作成ライブラリ（qrcode-generator, MIT）
├ img/           キツネの絵（ねている／おきている）
├ js/media.js    YouTube・音声・別ウィンドウの表示
└ js/app.js      上をつなぐ本体
```
本文の読み上げ（カメラ＋OCR）は今まで通り `v2/` で使えます。設計書はリポジトリ直下の `DESIGN.md`。

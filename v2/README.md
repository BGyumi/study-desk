# AI学習デスク v2

## 使い方
- 開く: `https://bgyumi.github.io/study-desk/v2/`
- こどもモード（起動時）: 本を置く →「📖 よんで」だけ。段落をタップするとそこから読む
- おやモード: 左上のロゴを **1.5秒長押し**。カメラ・ピント・APIキー・読み上げ速度を設定

## v1からの主な変更
| 問題 | 原因 | v2の対策 |
|---|---|---|
| QRが読めない | 画像を縮小してから探していたので小さいQRを取りこぼし／ボケに弱いjsQR | Chrome内蔵→ZXing（等倍）→ZXing＋ボケ補正の3段。テスト30枚で 9→17枚に改善。読めないQRが見えたら「もう少し大きく」と子どもに表示 |
| OCRが使えない | Tesseractはカメラ写真の日本語・縦書き・ふりがなに弱い | ClaudeのAI画像読み取りを本命に（縦書き・ルビ除外・段落分け）。Tesseractは予備 |
| ピントが合わない | オートフォーカスを有効化していなかった／固定焦点カメラの距離不足 | 対応カメラはAF自動ON・手動ピント/ズームを表示。ピント◎○×表示。撮影時は約1秒でいちばんシャープな瞬間を自動選択 |

## ファイル構成（役割ごとに分割）
```
v2/
├ index.html     画面の骨組み
├ css/style.css  見た目
├ js/config.js   設定値（モデル名・しきい値など）← 数字を変えたい時はここ
├ js/app.js      画面と部品をつなぐ本体
├ js/camera.js   カメラ・ピント・撮影
├ js/qr.js       QRコード
├ js/ocr.js      文字の読み取り
├ js/speech.js   読み上げ
├ js/ai.js       Claude APIへの通信（ここだけがAPIを呼ぶ）
└ vendor/        QRライブラリ（ZXing・同梱。ネット不要）
```
新機能（音読チェック・学習履歴など）は `js/` にファイルを1つ足して `app.js` からつなぐ形で増やします。
